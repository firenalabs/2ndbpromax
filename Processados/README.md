# Processados

Os arquivos recebidos em **Entrada** são movidos para cá depois que a digestão foi salva.

O original também permanece conservado em **Originais**. Os resultados ficam em **Digestões** e, nas próximas etapas, em Atlas, Diário e Conquistas.

Estar aqui significa que a digestão terminou; não significa que o grupo do Diário foi concluído.
