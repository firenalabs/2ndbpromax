# Digestões

Resultado do primeiro processamento de cada texto.

- Abra **.md** para ler os tópicos, bullet points, texto original e texto segmentado.
- **.json** guarda o objeto completo que os próximos fluxos usarão.

`SEG_00001`, `SEG_00002` etc. identificam frases daquele texto. Os KeyTopics usam esses marcadores para indicar onde começa cada ideia. Não precisa editar os marcadores nem interpretar os IDs no nome do arquivo.
