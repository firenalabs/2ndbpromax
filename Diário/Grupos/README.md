# Grupos de textos

Aqui ficam os textos originais reunidos em ordem, separados por duas quebras de linha. Cada grupo tem um JSON completo e um Markdown para leitura.

Um grupo **aberto** aguarda o próximo input. Ele permanece aberto ao parar o programa, terminar um lote ou passar muito tempo. Um grupo **concluído** recebeu uma quebra de continuidade identificada pelo Jev e pode gerar Diário e Conquistas.

Para acompanhar o grupo atual, prefira **Grupo em andamento.md**, na pasta acima. Para ler os registros finalizados, abra os outros Markdown na pasta Diário. Estes arquivos são gerados automaticamente; não precisa editá-los.
