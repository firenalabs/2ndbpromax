# Diário

Aqui ficam os registros de Diário, com título, resumo, aspectos identificados, KeyTopics por origem e referências às conquistas. Abra os **.md** para leitura; os **.json** guardam os dados completos.

**Grupo em andamento.md** mostra os textos que aguardam o próximo input. Um registro final só aparece quando o Jev identifica que o novo texto não continua o anterior. Esse novo texto inicia outro grupo. Pausa, fim do lote e reinício não fecham a janela.

**Grupos/** conserva os textos completos de todos os grupos, abertos e concluídos. Os arquivos são gerados automaticamente. Se houver falha na geração, os textos ficam preservados e a opção **Tentar novamente** retoma os documentos pendentes.
