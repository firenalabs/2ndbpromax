# Conquistas — Brag Document

Aqui ficam as conquistas identificadas nos grupos concluídos: evento, descrição do valor gerado, categoria e trecho literal que fundamenta a conquista.

Abra **.md** para leitura; **.json** guarda os dados completos. Os nomes começam com data e nome do evento; o identificador final diferencia os registros.

Os registros aparecem quando o Jev identifica uma vitória e o Agent consegue extrair uma conquista factual. Cada conquista referencia o grupo e os textos originais. Se uma chamada falhar, o Diário permanece salvo e a opção **Tentar novamente** retoma a extração.
