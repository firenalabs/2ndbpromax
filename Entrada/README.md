# Entrada

Coloque aqui arquivos **.txt**, salvos como texto UTF-8, com qualquer nome. Não precisa numerar os arquivos.

Inicie o programa por `iniciar.bat` no Windows ou `iniciar.sh` no Linux/macOS, na raiz desta cópia. A tela mostra o caminho completo da Entrada monitorada: coloque o arquivo exatamente nessa pasta. Ele aguardará a cópia terminar, processará um arquivo de cada vez e moverá os arquivos concluídos para **Processados**.

No Windows, confira a extensão completa do arquivo no Explorador. A janela deve anunciar “Encontrado na Entrada” ao detectar um `.txt`. Se ela estiver com texto selecionado e parecer parada, pressione Esc. Arquivos de outro tipo e arquivos já registrados nesta cópia recebem uma explicação na tela.

Para textos que precisam seguir uma sequência, adicione-os na ordem desejada. Arquivos encontrados juntos são ordenados automaticamente pela data de modificação, depois pelo nome.
